Sobre mí

Hola, soy Randy Leandro Cabrera, un desarrollador en formación con pasión por resolver problemas a través del código. Me encuentro en una etapa emocionante de mi carrera, dominando los fundamentos de la programación y construyendo proyectos cada vez más complejos.

Mi enfoque principal ha sido C# y la programación orientada a objetos, desarrollando sistemas como cajeros automáticos, gestión de empleados y simulaciones bancarias. También he trabajado en desarrollo web full-stack con React, TypeScript, Node.js y múltiples motores de bases de datos.

Manejo herramientas como Postman para testing de APIs, SQL Server y Oracle para bases de datos empresariales, y Docker para entornos de contenedores. Sigo creciendo, commit a commit.
